# Gleamy?

**Gleamy** started as a static Figma mockup — it's now a fully interactive web experience powered by React and Motion. Every transition, hover, and scroll interaction has been crafted to feel fluid and alive.

---

## 🎬 Preview
![video](src/assets/gleamy.gif)


- 🎨 **Pixel-perfect Figma to React** — every component faithfully translated from the original design
- 🌀 **Smooth animations** — powered by [Motion](https://motion.dev/) for buttery transitions
- 📱 **Responsive layout** — looks great on all screen sizes
 

---

 
 

##  Getting Started

```bash
# Clone the repo
git clone https://github.com/minhaj-my/gleamy.git
cd gleamy

# Install dependencies
bun install

# Start dev server
bun run dev
```
 
 
---

## 🎨 Design

The original design was created in **Figma**. The live site stays true to the source while adding layers of interactivity that static mockups can't express.
